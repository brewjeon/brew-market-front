# brew-market-front

지역 기반 거래 서비스 `brew-market`의 프론트엔드 저장소입니다.

## 구조

```text
apps
├─ web
└─ mobile
```
- `apps/web`: React와 TypeScript 기반 서비스 화면
- `apps/mobile`: React Native WebView 앱과 네이티브 기능 (예정)

## 웹 실행

Node.js 22.12 이상과 npm이 필요합니다. 백엔드를 localhost:8080에서 먼저 실행합니다.
이 저장소 루트에서 실행합니다.

```bash
npm install
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 처음 설치하면 생성되는
package-lock.json도 의존성 버전 고정을 위해 커밋합니다.

## 구현 범위

- 로그인 없이 최신 게시글 목록 조회
- 목록 선택 시 상세 조회, 브라우저 뒤로 가기 지원
- 가격, 나눔, 거래 상태와 상세 본문·작성 시각 표시
- 로딩, 빈 목록, 요청 실패 시 재시도, 없는 게시글 안내

개발 서버는 `/api/posts` 요청을 백엔드의 `/posts`로 전달합니다.
상세 주소는 `/#/posts/1` 형식입니다.
개발 프록시는 배포 결과물에 포함되지 않으므로 배포 시 `/api`를 백엔드로
전달하는 별도의 서버 설정이 필요합니다.

## 직접 확인

1. 백엔드에 등록한 글이 목록에 표시되는지 확인합니다.
2. 글을 눌러 본문과 작성 시각을 확인하고, 뒤로 가기로 목록에 돌아갑니다.
3. 없는 글 번호를 주소에 넣어 찾을 수 없다는 안내를 확인합니다.
4. 백엔드를 중지하고 새로고침하면 오류가 표시되는지 확인합니다.
5. 백엔드를 다시 켜고 다시 시도 버튼으로 복구되는지 확인합니다.

```bash
npm run build
```

빌드는 TypeScript 검사 후 배포용 파일을 생성합니다. 현재 변경에 대해 설치·실행·빌드는 아직 확인하지 않았습니다.

## 로그인과 게시글 관리

- 구글 로그인 버튼은 같은 창에서 localhost:8080의 기존 인증 경로로 이동합니다.
- 백엔드 local 프로필의 로그인 성공 주소는 http://localhost:5173/ 입니다. 로그인 성공 후 목록 화면으로 돌아와 세션을 확인합니다.
- 백엔드 설정 변경 후 local 프로필로 서버를 다시 시작해야 합니다. 구글에 등록한 백엔드 콜백 주소는 변경하지 않습니다.
- localhost:5173과 localhost:8080을 함께 사용합니다. 127.0.0.1과 섞지 않습니다. 세션 쿠키는 동일 호스트에서 포트와 무관하게 공유됩니다.
- 백엔드의 구글 인증 설정 및 기존 localhost:8080 콜백 주소가 필요합니다.
- 로그인 후 글쓰기, 수정, 삭제, 로그아웃을 사용할 수 있습니다. 변경 요청에는 현재 세션의 CSRF 토큰을 함께 보냅니다.
- 서버는 인증된 회원과 작성자를 비교해 상세 응답의 canManage를 결정합니다. 화면은 이 값이 true일 때만 수정·삭제 버튼을 표시하며, 실제 변경 요청의 서버 권한 검사도 유지합니다.
- 등록 후 생성된 상세 화면으로 이동하고, 수정 후 재조회하며, 삭제 후 목록으로 이동합니다.
- 삭제 확인, 저장 중 중복 제출 방지, 입력값 검증과 401·403·404·409 안내를 포함합니다.
- 거래 상태 변경·회원 탈퇴는 현재 연결한 API 범위에 포함되지 않습니다.

추가 확인 순서: 구글 로그인 → 글 등록 → 수정 후 새로고침 → 삭제 → 목록 제외 확인 → 로그아웃.
다른 회원으로 로그인했을 때 수정·삭제가 거부되는지도 확인합니다.
현재 로그인 주소와 개발 프록시는 로컬 환경용입니다. 운영 배포 시 도메인·콜백·로그인 복귀 주소를 별도로 설정해야 합니다.
